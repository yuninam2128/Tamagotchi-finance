# 지갑몬 시연 가이드

편집 없이 처음부터 끝까지 한 번에 찍는 약 55초짜리 시연이다. 시연 모드는 시나리오 순서대로 화면이 이어지게 맞춰져 있다. 가짜 데이터로 돌아가서 실제 계정과 랭킹에는 아무것도 남지 않는다.

| 장 | 길이 | 내레이션 |
|---|---|---|
| 1. 매일 3분 돌보기 | 약 18초 | 출퇴근길 3분, 지갑몬을 돌보며 문제를 풀면 그 자리에서 진짜 돈이 쌓입니다. |
| 2. 배우면 진화한다 | 약 12초 | 약점을 채우면 지갑몬이 진화하고, 배운 순간 필요한 상품까지 이어집니다. |
| 3. 모은 돈은 진짜 돈 | 약 9초 | 매일 18시에 예보 결과가 발표되고, 모은 돈은 제휴처에서 바로 바꿉니다. |
| 4. 졸업하고 다시 키운다 | 약 16초 | 다 키운 지갑몬은 졸업하고, 다음 세대는 가장 약한 힘을 골라 다시 키웁니다. |

## 1. 시연 모드 들어가기

아이폰 Safari에서 아래 주소를 연다.

```
https://tamagotchi-fin.vercel.app/?demo=rec
```

- 열면 **팝업 없이 바로 홈**이 나온다. 이게 시작 화면이다.
- 왼쪽 위의 작은 흐린 점이 시연 메뉴다. 촬영 중에는 누를 일이 없다.
- 시연 모드는 그 탭을 닫을 때까지 유지된다.
- 홈 화면에 설치한 지갑몬 아이콘으로 열면 일반 모드로 열린다. 시연은 Safari에서 위 주소로 연다.
- 녹화 없이 직접 보여줄 때는 `?demo=rec` 대신 `?demo`로 열면 위쪽에 "시연 모드 · 메뉴" 버튼이 보인다.

## 2. 찍기 전에

- 방해 금지 모드를 켜고 화면 밝기를 최대로 한다.
- 제어 센터 → 화면 기록으로 녹화한다.
- **리허설을 한 번 하고 찍는다.** 3D 모델이 처음 한 번 내려받아진 뒤에는 바로 뜬다.
- 리허설 뒤나 실수했을 때: 왼쪽 위 점 → **시연 처음으로 (재촬영)**. 또는 탭을 닫고 위 주소를 새 탭에서 다시 연다.
- 문제는 **정답만** 고른다. 리볼빙 문제를 틀리면 신용이 60에 못 닿아서 진화가 나오지 않는다.

| 문제 | 정답 |
|---|---|
| 1. [금융감독원] 앱 설치 문자 | **사기** |
| 2. 매매가 2억 빌라에 전세 1억 9천 | **깡통전세 위험이 크다** |
| 3. 리볼빙을 계속 쓰면 | **수수료가 쌓여 빚이 불어난다** |

## 3. 촬영 순서

### 1장. 매일 3분 돌보기 (약 18초)

| 하는 것 | 화면 |
|---|---|
| 시작 화면에서 2초 기다린다 | 3D 지갑몬이 둥둥 떠 있고, 말풍선에 "신용왕이 되려면 신용 60이 필요해. 지금 57!" |
| 지갑몬을 손가락으로 살짝 돌린다 | 옆면이 보인다 |
| **코스피** 우표를 누른다 → **오른다** | 우표에 화살표. 환율·비트코인은 이미 골라져 있다 |
| **계속 돌보기 (3)** | 사기 문자 문제 |
| 문자를 1초 보여주고 **사기** → **정답 확인** | 연두색 정답, 코인이 튀며 **+5원** |

### 2장. 배우면 진화한다 (약 12초)

| 하는 것 | 화면 |
|---|---|
| **계속하기** → 전세 문제 → **깡통전세 위험이 크다** → **정답 확인** | 해설 + 출처 + **제휴** 카드(예시보증). 카드가 버튼에 가리면 살짝 올려서 보여준다 |
| **계속하기** → 리볼빙 문제 → **수수료가 쌓여 빚이 불어난다** → **정답 확인** | 말풍선 **"신용 57→60"** |
| **계속하기** → 완료 화면 → **홈으로** | **신용왕 지갑몬** 진화 팝업 |
| **친구에게 자랑하기** | 아이폰 공유창이 올라온다 → 1초 뒤 바깥을 눌러 닫는다 |

### 3장. 모은 돈은 진짜 돈 (약 9초)

| 하는 것 | 화면 |
|---|---|
| 진화 팝업의 **닫기** | 0.5초 뒤 **예보 결과 발표** 팝업이 자동으로 뜬다. 2/3 적중 +40원 |
| **확인** → 오른쪽 위 **코인**을 누른다 | 내 지갑 **2,007원**, 교환 목표 진행 바 |
| **편의점 아메리카노**의 **교환하기** | 바코드 교환권 |

### 4장. 졸업하고 다시 키운다 (약 16초)

| 하는 것 | 화면 |
|---|---|
| 교환권의 **확인** | **"7일 뒤"** 화면이 2초 지나가고, 홈 지갑몬 아래에 졸업 카드가 생긴다 |
| **졸업식 하기** | 신용왕 졸업, 3세대, 성장폭 |
| **새 알 고르러 가기** | 알 고르기. **흐름 알**에 "추천" |
| **흐름 알로 시작하기** | **아기 지갑몬** 부화 팝업 → **닫기** |
| 홈을 조금 내려서 **도감** 미리보기를 누른다 | 도감 **3/5** |
| 왼쪽 위 **←** → 홈을 내려서 랭킹 **전체 보기** | 리그 순위 |
| 화면 아래 친구 리그 **만들기** | 맨 위에 "친구 리그 JGM2K7", 버튼이 **초대하기**로 바뀐다. 여기서 끝 |

## 4. 잘 안 될 때

| 상황 | 해결 |
|---|---|
| 처음 열었는데 결과 팝업이 뜬다 | 이전 시연이 남아 있다. 탭을 닫고 새 탭에서 다시 열거나 **시연 처음으로** |
| 진화 팝업이 안 뜬다 (문제를 틀림) | **시연 처음으로** 누르고 처음부터 |
| 교환하기가 회색이다 | 잔액이 2,000원 미만. 오늘 문제를 다 풀었는지 확인한다 |
| 공유창이 안 닫힌다 | 공유창 바깥(위쪽)을 누르거나 아래로 내린다 |
| 알 고르기 화면에서 나갔다 | 홈으로 가면 자동으로 알 고르기로 돌아온다 |
| 3D가 늦게 뜬다 | 첫 로딩만 1~2초. 리허설을 한 번 하고 찍는다 |

## 5. 멘트 주의

- **"진짜 돈", "제휴처에서 바로 바꿉니다"**: 지금은 제휴처가 없고 교환은 시연에서만 된다. 교환권에도 "시연용 쿠폰이라 실제로는 쓸 수 없어"라고 나온다. 투자자나 심사위원 앞이면 "제휴처가 붙으면 바로 바꿀 수 있습니다"처럼 계획으로 말하는 게 안전하다.
- **제휴 카드**: 예시보증·예시은행은 가상의 회사다. "제휴 상품이 이렇게 붙습니다" 정도로 소개한다.
- **"가장 약한 힘을 골라"**: 앱은 아직 도감에 없는 모습 중 가장 약한 힘을 **추천**하고, 고르는 건 사용자다.
- **캐릭터 그림**: 성체 모습별 그림이 아직 없어서 진화·졸업·도감에서 모든 모습이 같은 그림으로 나온다. 그림 5개가 들어온 뒤에 찍으면 2장과 4장이 훨씬 좋아진다. 넣는 방법은 `src/components/pet/sprites.ts`에 적혀 있다.
